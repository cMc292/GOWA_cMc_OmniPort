# Capturas del repositorio

Capturas del launcher que salen en el README (sección **Capturas**). Todas son del programa en ejecución; el fondo
lleva el arte de portada del juego, puesto por el dueño del repo en su copia local (`assets/launcher-bg.jpg`).

| Archivo | Página |
|---|---|
| `launcher-home.png` | HOME (también es la imagen de cabecera del README) |
| `launcher-graficos.png` | GRÁFICOS: resolución interna, FSR, generación de fotogramas, antialiasing |
| `launcher-pantalla.png` | PANTALLA: ventana, VSync, límite de FPS, ultrapanorámica |
| `launcher-controles.png` | CONTROLES: dispositivo, API del mando, zona muerta, vibración |
| `launcher-parches.png` | PARCHES: MLAA, profundidad de campo, motion blur, recorte de malla, sombras |
| `launcher-cheats.png` | CHEATS: daños, orbes, magia, furia, saltos |
| `launcher-sistema.png` | SISTEMA: idioma, guardados, audio, altavoces |
| `launcher-avanzado.png` | AVANZADO: versión, créditos y herramientas del paquete |
| `launcher-log.png` | LOG: registro de la última sesión |
| `launcher-trofeos.png` | TROFEOS: lista del `TROPHY.TRP` con iconos y progreso |
| `precompilacion-lectura.png` | Pantalla de precompilación (F7): «Leyendo los archivos del juego» |
| `banner.png` | Banner de diseño propio, sin arte del juego (respaldo por si se quiere quitar la captura) |
| `social-preview.png` | Previsualización social del repo (1280×640), de diseño propio |

> El arte de portada de las capturas es de **Santa Monica Studio / Sony** y no lo cubre la licencia MIT del
> proyecto. Se incluye como captura del programa; si en algún momento hay un problema de derechos, se sustituyen por
> capturas con el **fondo procedural** (sin arte del juego) y no afecta al funcionamiento del repo.

## Cómo hacer más capturas

Con el **fondo procedural** (sin la portada) para que sean solo tuyas:

1. En la carpeta del paquete, quita (o renombra) `assets\launcher-bg.jpg`, `assets\launcher-bg.png` y
   `assets\launcher-logo.png` si existen.
2. Abre `Launcher GOWA-cMc.exe` y ve a la página que quieras.
3. Captura con `Win+Mayús+S` o `Alt+ImprPant` y guarda el `.png` aquí con el nombre de la página
   (`launcher-<pagina>.png`).
4. Añádela a la tabla de la sección **Capturas** del README.
